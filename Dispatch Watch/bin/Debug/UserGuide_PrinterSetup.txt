Internet Explorer is not Available in Windows 11, Edge is launched per default.
The Print "Page Setup" has to be adapted in INTERNET EXPLORER for the application to export the pdf file properly (margins, and background colors)

*****************************************************************
Trick to open Internet Explorer:
Type Internet Options in the Start menu search bar.
Open the Control Panel applet that appears in the results.
Find the Programs tab and click Manage add-ons.
Finally, click Learn more about toolbars and extensions in the bottom-left corner of the window.
For some strange reason, this will launch Internet Explorer, bypassing the commands that normally force you into Edge.
*****************************************************************
Once Internet Explorer is finally opened:
Than click on the "Tools" wheel on top right corner
-> Print
-> Page Setup
-> tick "Print Background Colors and Images"
-> Header And Footers : all fields to "Empty"
